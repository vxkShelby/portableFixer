## New

- **Export diagnostics button** (sysinfo panel) - zips up your Logs/Reports into one file you can attach to a bug report.
- **Crash log**: uncaught errors are now written to `Logs/crash.log` instead of vanishing silently (the app is built with `--noconsole`, so before this there was no trace of them at all).

Full history since v1.10.0: see the [commit log](https://github.com/vxkShelby/portableFixer/compare/v1.10.0...v1.11.0).
